# FreeSWITCH 配套目录

阶段 3 在这里添加授权脚本、拨号计划与 mod_json_cdr 配置。测试机的准备要求见 [准备清单](../docs/freeswitch.md)。

## 被叫号码规范化（阶段 1 约定）

拨号计划必须在调用授权接口和推送话单之前去掉被叫号码开头的 `+` 或 `00`，只传纯数字（如 `44712345678`）。计费系统不做规范化：`+44712345678`、`0044712345678` 或含非数字字符的号码在**授权接口**一律以 `号码格式错误` 拒绝（阶段 3 返回 400）。**话单接口不返回 400**：按 design.md §4.3 话单不能丢，这类话单照常接收保存，作为未归属/待人工处理话单（不自动扣费），并写系统告警。
