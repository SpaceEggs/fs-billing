# db/admin — 管理后台写入服务

## 职责

管理后台的写入与聚合服务：租户开户与设置、资金操作、费率版本与 CSV 预览、待收款状态流转。

## 边界

- 只被 `apps/api` 调用；Worker 与门户读模型不使用这些服务（它们需要管理员身份与租户锁）。
- 每个操作在 `withAdmin` 事务内完成，操作日志（`writeAudit`）与业务写入同事务提交；失败以 `AdminServiceError` 携带稳定错误码返回给 API。操作日志的查询走只读角色 `fs_billing_audit`，还没有后台页面。
- 业务规则（金额精度、待收款状态机、调价与排定）由 `architecture`（design.md §6、§7）定义，这里不重复。

## 不变量

- 人工金额操作按类型校验小数位（充值/赊账/赠送 2 位，调账 4 位）与整数位上界，超限直接拒绝，不四舍五入。
- 赊账充值的收款事件只追加：确认、撤销确认、作废都不改余额与原流水。
- 调价只能追加版本；有排定版本时禁止单条编辑、导入与复制；取消排定必须早于生效时间 60 秒以上（余量可配，按数据库时间判断）。
- CSV 导入先预览（60 分钟内有效，可配）再提交；提交时重新校验费率版本与生效时间，预览过期返回冲突。
- 费率复制的源与目标必须同币种。
