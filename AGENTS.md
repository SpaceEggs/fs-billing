# Agent 约定

发现一类 bug，就加一条机器强制。修完后跑 `/correct`：架构 → 类型 → 报错能点出改法的 lint → 测试 → CI probe，并在下表加一行。

`pnpm check` 必须通过。Node 24.22.2（`.node-version`）。验证技能：`.cursor/skills/verify-fs-billing/SKILL.md`。

## 规则 → 由什么强制 → 位置/证明

| --------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 金额不得用 number 运算                                          | ESLint `money/no-number-money`                                                                                   | `tooling/eslint/money.ts`；`tests/money-rule.test.ts`；CI `Reject native floating point money arithmetic`                                                                                                                                                          |

## 工作流

1. 先修 bug。
2. 把这一类再犯变成不可能（上表那条链）。
3. `pnpm check` 绿了再交。
