# FS-Billing 页面说明书

> 版本：v0.1（2026-09-29）
> 用途：作为 Claude Design 的设计输入。业务规则以 `docs/design.md` 为准。

---

## 0. 如何在 Claude Design 中使用本文档

**建议的步骤：**

1. 先把第 1 节「全局规范」交给 Claude Design，确定设计系统（颜色、字体、组件、状态标签），浅色和深色都要出
2. 设计第一批页面（见第 4 节「设计顺序」），电脑版和手机版都要出
3. 第一批满意后，再做第二批、第三批
4. 每个页面最后补上「状态」一栏里列出的特殊情况

**可以直接使用的开场提示词：**

> 请为一个 SIP 话务计费系统设计界面，包含"客户门户"和"管理后台"两部分。
> 使用 shadcn/ui 的组件风格（基于 Tailwind），界面语言为简体中文。
> 需要同时支持浅色和深色模式，并适配手机布局。
> 风格要求：简洁、专业、信息密度适中，以表格和数字为主，类似现代 SaaS 后台。
> 先根据以下全局规范建立设计系统，暂时不要设计具体页面：
> （粘贴第 1 节）

之后每次设计一个页面，粘贴该页面的说明即可。

## 1. 全局规范

### 1.1 基本要求

| 项目 | 要求 |
|---|---|
| 组件风格 | shadcn/ui（开发时使用同一套组件库） |
| 语言 | 简体中文 |
| 主题 | 浅色 / 深色 / 跟随系统，默认跟随系统；切换入口在右上角 |
| 适配 | 电脑和手机都要适配 |
| 字体 | 系统字体（苹方 / 微软雅黑 / 思源黑体），不使用网络字体 |
| 数字 | 金额、时长、费率使用**等宽数字**，表格中右对齐 |

### 1.2 数据格式

| 类型 | 格式 | 示例 |
|---|---|---|
| 日期时间 | `YYYY-MM-DD HH:mm:ss`（北京时间） | 2026-09-29 14:03:22 |
| 日期 | `YYYY-MM-DD` | 2026-09-29 |
| 月份 | `YYYY年M月` | 2026年9月 |
| 金额 | 币种符号 + 千分位 + 2 位小数 | ¥1,234.56 / $1,234.56 |
| 负数金额 | 负号 + 红色 | -¥56.20 |
| 费率 | 4 位小数 + 单位 | 0.0450 元/分钟 / $0.0120/分钟 |
| 通话时长 | 分秒 | 3分50秒 |
| 计费时长 | 整分钟 | 4分钟 |
| 被叫号码 | 完整号码，不隐藏 | 8613800138000 |

### 1.3 状态标签颜色

浅色和深色模式下都必须清晰可辨。

| 标签 | 颜色 | 使用场景 |
|---|---|---|
| 正常 | 绿色 | 租户状态 |
| 余额不足 | 橙色 | 余额低于提醒阈值 |
| 透支中 | 橙色 | 余额为负但未超过透支额度 |
| 已停机 | 红色 | 余额 + 透支额度已用完 |
| 已停用 | 灰色 | 管理员停用的租户 |
| 已收款 | 绿色 | 充值记录 |
| 待收款 | 橙色 | 赊账充值 |
| 未经验证 | 黄色/琥珀色 | 计费系统故障期间放行的话单（**仅管理后台显示**） |
| 已接通 / 未接通 | 默认色 / 灰色 | 话单 |

### 1.4 布局

| | 电脑 | 手机 |
|---|---|---|
| 导航 | 左侧固定菜单 | 左上角菜单按钮，点击展开抽屉 |
| 顶栏 | 右侧：主题切换、账号菜单 | 同左，但更紧凑 |
| 表格 | 普通表格，显示全部列 | 每行变为一张**卡片**，只显示关键字段，点击查看详情 |
| 筛选条件 | 表格上方横向排列 | 收进"筛选"按钮，点击后从底部弹出 |
| 弹窗 | 居中对话框 | 从底部弹出的全宽面板 |

### 1.5 通用状态（每个列表页都要考虑）

- 加载中（骨架屏）
- 没有数据（空状态插图 + 说明文字）
- 筛选结果为空（提示并提供"清除筛选"按钮）
- 加载失败（错误提示 + "重试"按钮）

## 2. 客户门户

菜单：**首页、话单、月账单、余额流水、账号设置**

> 客户门户**不显示费率表**，也不提供任何删除话单的功能。

### 2.1 登录页

| 项目 | 内容 |
|---|---|
| 使用者 | 客户 |
| 字段 | 登录邮箱、密码 |
| 操作 | 登录 |
| 说明 | 没有注册入口；忘记密码提示"请联系客服重置"；密码框可切换显示/隐藏 |
| 状态 | 账号或密码错误（不提示具体是哪个错）；账号已停用；连续失败 5 次后锁定 15 分钟（显示剩余时间）；登录已过期，请重新登录 |
| 手机 | 单列居中，输入框和按钮高度 44px |

### 2.2 首页

| 项目 | 内容 |
|---|---|
| 目的 | 一眼看到账户状况 |
| 顶部指标卡片 | **当前余额**（负数显示红色）、透支额度、**本月消费**、本月通话分钟数 |
| 账户状态 | 状态标签（正常 / 余额不足 / 透支中 / 已停机） |
| 图表 | 最近 30 天每日消费金额（柱状图） |
| 列表 | 最近 10 通话单，带"查看全部"链接 |
| 手机 | 指标卡片 2×2 排列；图表可横向滑动；最近话单为卡片 |
| 状态 | 新客户没有任何话单；**已停机**时顶部显示醒目提示"余额不足，已暂停呼叫，请联系客服充值" |

### 2.3 话单

| 项目 | 内容 |
|---|---|
| 目的 | 查找通话记录、核对费用、导出 |
| 表格列 | 接通时间、主叫号码、被叫号码、国家/备注、通话时长、计费时长、费率、费用 |
| 筛选 | 日期范围（默认本月，最长一个月；点击弹出日历选择器，电脑和手机都显示"最长一个月"提示）、被叫号码（模糊搜索）、国家、接通状态（默认"已接通"，可选"全部"） |
| 汇总栏 | 筛选结果的通话数、总计费分钟、总费用 |
| 操作 | 导出 CSV（按当前筛选条件）；点击一行查看详情 |
| 详情 | 以上全部字段 + 振铃开始时间、挂断时间、挂断原因、匹配的前缀、通话 UUID |
| 分页 | 每页 50 条 |
| 手机 | 卡片显示：接通时间、被叫号码、国家、通话时长、费用 |
| 状态 | 未接通的话单为灰色且费用为 0 |
| 注意 | 客户门户**不显示**"未经验证"标签及任何与计费系统故障有关的信息，这些只在管理后台显示 |

### 2.4 月账单列表

| 项目 | 内容 |
|---|---|
| 表格列 | 月份、期初余额、充值、赠送、调账、通话扣费、期末余额、通话分钟数（手机和窄屏可只显示期初、通话扣费、期末） |
| 操作 | 点击查看详情 |
| 状态 | 当月尚未结束时显示"本月（进行中）"，数据实时更新 |

### 2.5 月账单详情

| 项目 | 内容 |
|---|---|
| 顶部 | 月份、租户名称、币种 |
| 汇总区 | 期初余额 + 充值 + 赠送 ± 调账 − 通话扣费 = 期末余额（做成清晰的算式；赠送或调账为 0 时该项仍显示 0.00，调账为负数时显示红色负数）<br>"充值"包含赊账充值（对客户不区分） |
| 按国家汇总 | 国家/备注、通话数、计费分钟、费用；按费用从高到低排序 |
| 按日汇总 | 日期、通话数、计费分钟、费用 |
| 操作 | 导出 CSV（汇总）、导出 CSV（该月话单明细）、打印 |
| 状态 | 该月话单已被管理员删除时，"导出话单明细"按钮不可用，并提示"该月话单明细已删除" |

### 2.6 余额流水

| 项目 | 内容 |
|---|---|
| 目的 | 查看每一笔余额变动 |
| 表格列 | 时间、类型（充值 / 赠送 / 调账 / 通话扣费）、金额（+绿 / −红）、变动后余额、备注 |
| 说明 | 通话扣费**按天合并**成一条显示（例："2026-09-28 通话扣费，共 356 通"），点击可跳转到当天话单 |
| 筛选 | 日期范围、类型 |
| 操作 | 导出 CSV |
| 说明 | 客户看不到"待收款"等内部状态，赊账充值对客户显示为普通"充值" |

### 2.7 账号设置

| 项目 | 内容 |
|---|---|
| 内容 | 登录邮箱（只读）、租户名称和编码（只读）、币种（只读）、修改密码、主题选择 |
| 修改密码 | 需输入当前密码 + 新密码 + 确认新密码；新密码至少 8 位；成功后提示"密码已修改"，其他设备上的登录将失效 |
| 退出登录 | 页面底部提供"退出登录"按钮 |

## 3. 管理后台

菜单：**概览、租户、待收款、未归属话单、账单、系统告警、操作日志、管理员**

### 3.1 登录页

与客户门户类似，但标题注明"管理后台"，视觉上有所区分（使用管理后台的蓝色点缀），避免管理员和客户混淆。状态与客户登录页相同。

### 3.2 概览

| 项目 | 内容 |
|---|---|
| 指标卡片 | 租户总数、今日通话分钟、今日消费、本月消费、**待收款总额**、**已停机租户数** |
| 需要关注 | 已停机租户列表、余额不足租户列表、未归属话单数、系统告警（最近 24 小时） |
| 图表 | 最近 30 天每日消费（可按币种切换） |
| 说明 | CNY 和 USD 分开统计，不混加 |
| 交互 | "需要关注"中的每一项都可点击跳转（租户 → 租户详情，未归属话单 → 未归属话单页，告警 → 系统告警页）；没有需要关注的事项时显示"一切正常" |

### 3.3 租户列表

| 项目 | 内容 |
|---|---|
| 表格列 | 租户编码、名称、币种、状态标签、当前余额、透支额度、本月消费、待收款金额 |
| 筛选 | 搜索（编码/名称）、状态、币种 |
| 排序 | 先按状态：已停机 → 透支中 → 余额不足 → 正常 → 已停用；同一状态内再按余额从低到高。**不同币种的金额不能直接比较大小** |
| 操作 | 新建租户；点击进入详情；每行快捷"余额操作"按钮 |
| 手机 | 卡片：名称、编码、状态、余额 |

### 3.4 新建 / 编辑租户

| 字段 | 说明 |
|---|---|
| 租户编码 | 必填，字母数字，**创建后不可修改**，旁边提示"须与 FreeSWITCH 中的 billing_tenant 一致" |
| 租户名称 | 必填 |
| 币种 | CNY / USD，**创建后不可修改** |
| 透支额度 | 默认 CNY 100 / USD 15 |
| 余额提醒阈值 | 数字 |
| 通知邮箱 | 可添加多个 |
| 联系人、电话、备注 | 可选 |
| 门户账号 | 登录邮箱 + 初始密码（可自动生成） |
| 费率表 | 选择：空白 / 从 CSV 导入 / 复制某个租户的费率表 |

### 3.5 租户详情

顶部：租户名称、编码、状态标签、**当前余额（大字）**、透支额度、可用额度；右上角操作：余额操作、编辑、停用/启用。

下方分标签页：

| 标签页 | 内容 |
|---|---|
| **概况** | 本月消费、通话分钟、最近 30 天消费图 |
| **余额流水** | 同客户门户，但显示全部类型和收款状态、操作人 |
| **费率** | 见 3.6 |
| **话单** | 同客户门户的话单页，另外：显示"未经验证"黄色标签，详情中显示验证状态及说明（"计费系统故障期间由 FreeSWITCH 放行，最长 30 分钟"）；筛选条件增加"仅看未经验证"；有"删除话单"按钮（见 3.6.1） |
| **账单** | 同客户门户的月账单，另有"重新生成"按钮 |
| **设置** | 透支额度、提醒阈值、通知邮箱 |
| **门户账号** | 登录邮箱、最后登录时间、重置密码、停用账号 |

### 3.6 费率表（租户详情内的标签页）

| 项目 | 内容 |
|---|---|
| 表格列 | 前缀、国家/备注、费率、生效时间 |
| 功能 | 搜索前缀或国家；显示当前生效版本；如有排定的新版本，单独显示 |
| 操作 | 导入 CSV、导出 CSV、复制到其他租户、单条编辑 |
| 单条编辑 | 修改后必须确认：显示"旧费率 → 新费率"和涨跌幅，可选"立即生效"或"指定时间生效"（日期时间选择器），记入操作日志 |
| 复制到其他租户 | 对话框：① 选择目标租户（只能选**同币种**的租户）；② 醒目提示"将**覆盖**目标租户的整张费率表"；③ 复用导入流程的"预览变动"界面，显示目标租户的新增 / 修改 / 删除明细；④ 选择生效时间（立即 / 指定时间）；⑤ 确认后记入操作日志 |
| 手机 | 可查看和搜索；导入操作建议提示"请在电脑上操作" |

**导入 CSV 流程（对话框，分三步）：**

1. **上传**：选择文件；提供"下载 CSV 模板"链接；选择生效时间（立即 / 指定时间，指定时间用日期时间选择器）。提示文字："支持 UTF-8 / GBK 编码（Excel 默认保存格式即可）"，系统自动识别编码
2. **预览与校验**：
   - 成功：显示将新增 X 条、修改 Y 条、删除 Z 条，并列出变化明细（旧费率 → 新费率）；有删除项时提示"删除后，拨打这些前缀的呼叫将被拒绝"
   - 失败：显示错误列表，例如"第 37 行：费率不能为负数"，**不能继续**
3. **确认导入**：显示结果

### 3.6.1 删除话单（对话框）

从租户详情的"话单"标签页打开。话单默认永久保存，这是唯一的删除入口。

| 项目 | 内容 |
|---|---|
| 字段 | **按整月选择**：开始月份、结束月份（月份选择器） |
| 限制 | 只能选择**已生成月账单**的月份；当月（账单尚未生成）不可选，并提示原因 |
| 预览 | "将删除 ABC001 在 2024年1月 至 2024年6月 的 128,456 条话单" |
| 影响说明 | 醒目提示："删除后无法恢复。余额和已生成的月账单不受影响，但该时段将无法导出话单明细，也无法重新生成月账单。" |
| 确认 | 必须手动输入租户编码（如 `ABC001`）后，"删除"按钮才可点击；按钮为红色 |
| 结果 | 显示删除条数，并自动记入操作日志 |

### 3.7 余额操作（对话框）

从租户列表或租户详情打开。

| 字段 | 说明 |
|---|---|
| 操作类型 | 充值 / 赊账充值 / 赠送 / 调账 |
| 金额 | 调账允许负数，其他只能正数 |
| 备注 | 调账时**必填**；备注框旁标注"**客户可见**"（会显示在客户门户的余额流水中）。赊账充值例外：客户看到的是"账户充值"，备注不对客户显示，标注"仅内部可见" |
| 预览 | "当前余额 ¥-35.20 → 操作后 ¥464.80" |
| 确认 | 二次确认后提交 |

### 3.8 待收款

| 项目 | 内容 |
|---|---|
| 表格列 | 租户、赊账时间、金额、操作人、备注、已欠天数 |
| 汇总 | 待收款总额（按币种分开） |
| 操作 | "确认收款"（可填实际收款日期和备注） |
| 状态 | 欠款超过 30 天的行高亮 |

### 3.9 未归属话单

| 项目 | 内容 |
|---|---|
| 说明 | 租户标签缺失或找不到对应租户的话单 |
| 分组 | 顶部按租户标签分组汇总，例如"标签 ABC01（疑似拼写错误）· 326 条"、"标签为空 · 12 条"，点击分组筛选 |
| 表格列 | 接通时间、话单中的租户标签（可能为空）、主叫、被叫、通话时长 |
| 操作 | 勾选多条，或"选择该分组全部" → "归属到租户"；"忽略"（需填原因） |
| 归属确认 | 选择租户后显示预览：条数、将按该租户费率计算的扣费合计、匹配不到费率的条数（这些不能归属）；确认后扣费并记入操作日志 |
| 已忽略 | 单独的"已忽略"标签页，可查看忽略原因，可撤销忽略 |
| 提示 | 顶部说明"请同时检查 FreeSWITCH 中的 billing_tenant 配置" |

### 3.10 账单

| 项目 | 内容 |
|---|---|
| 内容 | 选择月份（月份选择器），列出所有租户该月的账单汇总；CNY 和 USD 分组显示合计 |
| 表格列 | 租户、币种、期初余额、充值、赠送、调账、通话扣费、期末余额、生成时间 |
| 操作 | 查看单个租户账单；重新生成（例如补推话单后） |

### 3.11 系统告警

| 项目 | 内容 |
|---|---|
| 表格列 | 时间、类型（授权超时 / 话单处理失败 / 邮件发送失败）、说明、状态（进行中 / 已恢复） |
| 设置 | 告警接收邮箱（可多个）、汇总邮件间隔（默认 15 分钟） |
| 详情 | 点击一条告警查看：开始时间、恢复时间、持续时长、影响的通话数（如"期间放行 23 通未经验证话单"，可跳转查看） |
| 导航 | 有"进行中"的告警时，左侧菜单"系统告警"旁显示红点 |

### 3.12 操作日志

| 项目 | 内容 |
|---|---|
| 表格列 | 时间、管理员、操作（新建租户 / 充值 / 调账 / 导入费率 / 删除话单 / 重置密码……）、对象、详情 |
| 筛选 | 日期范围、管理员、操作类型、租户 |
| 说明 | 只读，不可删除 |
| 详情 | 点击展开查看修改前后的值，例如"透支额度 ¥100.00 → ¥300.00"、"费率 447：0.0450 → 0.0480" |

### 3.13 管理员

| 项目 | 内容 |
|---|---|
| 内容 | 管理员列表（姓名、登录邮箱、状态、最后登录时间）、新增管理员、重置密码、停用 |
| 权限 | 第一版所有管理员权限相同 |
| 限制 | 不能停用自己；至少保留一个启用的管理员 |
| 重置密码 | 生成临时密码，只显示一次，提供"复制"按钮 |

### 3.14 全局元素

| 项目 | 内容 |
|---|---|
| 账号菜单 | 点击右上角头像弹出：姓名/邮箱、账号设置（客户门户）、退出登录 |
| 登录过期 | 操作时登录已过期，弹出提示并跳转到登录页，登录后回到原页面 |
| 找不到页面 | 404 页面，提供"返回首页" |

## 4. 设计顺序

| 批次 | 客户门户 | 管理后台 |
|---|---|---|
| **第一批** | 首页、话单 | 租户列表、租户详情（含余额流水标签页）、余额操作对话框 |
| **第二批** | 月账单列表与详情、余额流水 | 费率表 + CSV 导入流程、新建租户、待收款 |
| **第三批** | 登录、账号设置 | 租户详情其余标签页（概况、话单 + 删除话单对话框、账单、设置、门户账号）、概览、未归属话单、账单、系统告警、操作日志、管理员、登录；全局元素（账号菜单、登录过期、404） |

**每批检查要点：**

- [ ] 电脑版和手机版都有
- [ ] 浅色和深色都有（至少核心页面）
- [ ] 使用了第 1.6 节的真实感示例数据
- [ ] 包含负余额、已停机、空数据等特殊状态
- [ ] 金额和费率格式符合第 1.2 节
