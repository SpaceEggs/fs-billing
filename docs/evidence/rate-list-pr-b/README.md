## 视觉对照

截图在 [visual/](visual/)。每张 `compare-<页面>-<变体>.png` 左侧是设计稿画框，右侧是实现。完整运行生成 75 项，仓库只保留与费率页相关的 24 张 compare 图；`app-*.png`、`design-*.png` 和其他页面未提交，重新运行上面的命令即可生成。本机字体为 macOS 系统字体，不把字形差别算作差异。

视觉脚本的费率夹具改成带 ISO 与说明的新种子形状（447 为 GB / 英国 / 手机），导入 CSV 同时含「改费率」（86）、「只改说明」（852：空 → 港澳）、「ISO 变空」（65：SG → 空）、新增（33）和删除（1876），使变动表的 `旧 → 新` 可见。新增 `rates-edit-form`、`rates-edit-confirm` 两个场景对照设计稿 8a、8b；确认页改的是前缀 1（ISO 空 → US、国家 美国/加拿大 → 美国、说明 空 → 含加拿大、费率 0.0100 → 0.0120）。

人工逐张查看的结论：

- 费率页（浅色、深色）表头为 `ISO / 国家 / 号码前缀 / 说明 / 费率（元/分钟）`，行内同序；447 行显示 GB、英国、447、手机；前缀 1 的 ISO 为空，显示为空单元格。搜索框占位符「搜索前缀、ISO、国家或说明」。
- 费率页（手机 375 宽）每行只有前缀、`国家 · 说明`（447 为「英国 · 手机」）、带单位的费率，没有表头和单独的 ISO 列。
- 排定版本（浅色、深色）：卡片的变动表有 `变动 / ISO / 号码前缀 / 国家 / 说明 / 当前费率 / 新费率 / 涨跌`；当前表 447 行提示「10-22 起 0.0480」。
- 编辑对话框：前缀只读，ISO（提示「两位字母，可留空」）、国家（必填）、说明（提示「说明会显示在客户的话单里，请勿填写内部备注」）、费率。确认页逐项显示 `ISO：— → US`、`国家：美国/加拿大 → 美国`、`说明：— → 含加拿大`，旧值划线。
- 导入对话框：上传步的格式提示为 `ISO,Country,Destination Prefix,Description,Rate　每行一个前缀，覆盖整张费率表`，下一行「说明会显示给客户，请勿填写内部备注」，右下角「下载 CSV 模板」。预览步的变动表五列加 `旧 → 新`（`SG → —`、`— → 港澳`）。错误步的校验规则文字含「ISO 为两位字母或留空；国家必填」。

## 与设计的取舍

见本 PR 的回报。要点：「新费率与当前费率相同」的无变化提示沿用原文案，ISO 输入框的提示「两位字母，可留空」、变动表空值显示「—」、`旧 → 新` 里空值显示「—」是设计没写、按最保守做法加的。
