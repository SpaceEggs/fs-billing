# 阶段 8 话单运维视觉对照差异清单

对应 [plan.md](../../plan.md) 阶段 8 的「对应设计稿」：管理后台 第三批 · 运营（未归属话单、操作日志）、第三批 · 租户详情（删除话单对话框）。做法沿用阶段 6、7 的 [视觉对照](../phase-7-web/visual-diff.md)：逐个画框截取设计稿与实现，拼成左设计稿右实现的对照图，每张都由人查看（浅色 23 张全部看过；深色看了 3 张有代表性的，其余按浅色同位置核对，见[没有被这批截图覆盖的](#没有被这批截图覆盖的)）。

**比较对象是当前的 UI：** 网页已在 PR #71 改用 shadcn/ui 组件，所以这份清单同时记录该迁移带来的外观差异（[迁移带来的差异](#迁移带来的差异)），只记录、不修改产品代码。**没有改动任何产品代码**，只有 e2e 与文档。

**结论：** 23 个有画框的状态、各拍浅色与深色，共 46 张对照图，另有 4 个稿中没有画框的状态只存档（8 张）。版式与文案大体与稿一致；差异分三类：已有决定或夹具数据造成的（[已接受](#已接受的差异)）、shadcn 迁移带来的（[迁移带来的差异](#迁移带来的差异)）、没有现成决定而需要用户判断的（[待用户决定](#待用户决定)，7 项）。待用户决定的项都没有改代码。

## 没有被这批截图覆盖的

- 深色图只逐张看了 3 张（归属预览电脑、操作日志展开电脑、删除话单编码正确手机），其余 20 张深色按同一位置的浅色图核对（布局由同一份代码生成，主题只换令牌）；发现的深色差异只有 M7。

- 手机的 375 px 之外的宽度、1024 窄屏没有截。
- 租户话单标签页的已删除月份提示条与「删除话单」按钮（`app-tenant-cdrs-deleted-*`）没有稿画框，已逐张看过版式，只存档。
- 待处理清空后「最近一次处理」一行、已忽略页签的警示条见 P5。
- 稿 3h 的空状态用接口拦截渲染（库里有 338 条待处理，不能真的清空）。
