## 分类

- **(a)** 已决定的省略或改动。引用 [phase-5-design.md「已决定（阶段 5 Web 缺口，2026-10-15）」](../../phase-5-design.md#已决定阶段-5-web-缺口2026-10-15)（下称「缺口决定」）的条目、[phase-5-design.md「已决定（阶段 5 视觉对照，2026-10-17）」](../../phase-5-design.md#已决定阶段-5-视觉对照2026-10-17)（下称「视觉对照决定」，C8、C9、C12），或 [phase-4-web.md「与设计稿的差异」](../../phase-4-web.md#与设计稿的差异)。缺口决定写明「本阶段契约不支持的设计稿元素直接省略」，下文标「(a) 总则」的项目属于这一条但未逐项列出，并写明对应的契约字段。
- **(b)** 只是种子或测试数据不同：名称、编码、金额、日期、条数、排序、临时密码长度。
- **(c)** 实现上的 UI 缺陷，或未记录的偏离设计稿。编号见文末[缺陷处理](#缺陷处理)；已修复的项不再计入 (c)。
- **(d)** 对照方式造成，不是实现问题：画框与截图状态不同、设计稿各批之间不一致，或整页截图的伪影。
