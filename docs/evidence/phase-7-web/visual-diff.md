# 阶段 7 月账单视觉对照差异清单

对应 [plan.md](../../plan.md) 阶段 7 的「对应设计稿」：客户门户 第二批（月账单），管理后台 第三批 · 运营（账单）、第三批 · 租户详情（账单标签页）。做法沿用阶段 6 的 [视觉对照](../phase-6-web/visual-diff.md)：逐个画框截取设计稿与实现，拼成左设计稿右实现的对照图，每张都由人查看。

**结论：** 对照中发现 **1 处明确缺陷，已修正并复拍**（手机日表折行，见[本轮修正](#本轮修正)）。其余差异分为：已决定或属于画框外壳、种子或夹具数据的（[接受](#已接受的差异)），以及**没有现成决定、没有改动、列出来等用户决定**的（[未经决定的差异](#未经决定的差异)，共 9 项）。plan 阶段 7 的验收标准没有截图一项，所以这份清单不对应勾选。

## 没有被这批截图覆盖的

- 待生成月份、「没有已接通的通话」、⋯ 面板、「N 个未生成，不计入合计」、「账单已过期」「账单与流水不一致」「已重新生成」备注、重新生成成功与版本冲突提示：种子里没有对应状态，没有截图；由单元测试与 e2e 覆盖（见 [phase-7-design.md 验收映射](../../phase-7-design.md#验收标准对应计划测试)）。
- 打印效果：只验证了打印媒体下隐藏外壳与按钮（e2e `emulateMedia('print')`），没有人工看真实打印预览（设计风险一节已写，打印依赖浏览器）。
- 手机 375 px 之外的宽度（稿画框 390）没有截；窄屏 1024 只截了门户列表（稿 1b）。
- 夹具租户的名称、数字与稿不同，所以 3a/3b、4a/4b、1g/3g 只核对版式、文案和置灰状态，不核对数字。
